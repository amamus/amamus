# amamus iocum Website — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, test, review, and prepare for PR the production-ready static corporate website of amamus iocum (Astro + TypeScript) deployed to GitHub Pages under `/amamus/`.

**Architecture:** Astro 7 static site. Design tokens in `tokens.css`; Astro component design system; typed config in `src/config/site.config.ts`; pure utility modules (`src/utils/*`) covered by Vitest; pages in `src/pages/`; legal content as a content collection; Playwright e2e + axe-core a11y + Lighthouse audits against the production build; least-privilege GitHub Actions workflow deploying `dist/` to GitHub Pages.

**Tech Stack:** Astro ^7.4.13 (Node >=22.23.4; local Node 26), TypeScript ^5.9, @astrojs/check, @fontsource-variable/inter + @fontsource-variable/nunito-sans (self-hosted woff2), Vitest 5, Playwright 1.65 (+ downloaded Chromium), axe-core, Lighthouse 13 (via Playwright Chromium), sharp (asset generation), ESLint 10 + eslint-plugin-astro + typescript-eslint. No runtime framework, no state library, no backend, no trackers.

**Spec:** `docs/superpowers/specs/2026-11-22-amamus-website-design.md` — read it first; this plan implements it. Refinement vs. spec (approved direction, same substance): home section copy lives in one typed module `src/content/home.ts` (type-checked single source) instead of MDX; legal pages use a glob content collection of Markdown files with zod frontmatter schema; the sitemap is a hand-written endpoint `src/pages/sitemap.xml.ts` (no extra dependency, fully testable).

```ts
import type { SiteConfig } from '../config/site.config';

export function validateConfig(c: SiteConfig): { ok: true } | { ok: false; errors: string[] } {
  const errors: string[] = [];
  if (!/^https:\/\/[a-z0-9.-]+\/?$/i.test(c.siteUrl)) errors.push('siteUrl must be an https URL');
  if (!c.base.startsWith('/') || !c.base.endsWith('/')) errors.push('base must start and end with /');
  if (c.contact.email !== null && !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(c.contact.email))
    errors.push('contact.email must be a valid email or null');
  if (!c.name.trim()) errors.push('name must not be empty');
  return errors.length ? { ok: false, errors } : { ok: true };
}
```
